# Respostas das atividades

## Atividade 1

**Resposta:**

O arquivo `index.html` é onde fica a estrutura e o conteúdo da página, como os textos, títulos, imagens e links. O arquivo `style.css` é usado para mudar a aparência da página, como cores, tamanho da fonte e espaçamentos.

## Atividade 2

**Resposta:**

A declaração que deve ficar no começo é:

```html
<!DOCTYPE html>
```

Ela informa que a página está usando HTML5.

## Atividade 3

**Resposta:**

A tag usada para colocar o título que aparece na aba do navegador é a `<title>`.

## Atividade 4

**Resposta:**

A tag `<h1>` representa o título principal da página e a tag `<p>` representa um parágrafo.

## Atividade 5

**Resposta:**

A tag usada para criar uma seção temática de conteúdo é a `<section>`.

## Atividade 6

**Resposta:**

A tag usada para agrupar os links de navegação é a `<nav>`.

O atributo que define o destino do link é o `href`.

## Atividade 7

**Resposta:**

O atributo usado para identificar uma seção de forma única é o `id`.

Para apontar o link para uma seção chamada `sobre`, pode ser escrito assim:

```html
href="#sobre"
```

## Atividade 8

**Resposta:**

A tag usada para inserir uma imagem é a `<img>`.

O atributo que informa o caminho da imagem é o `src`.

## Atividade 9

**Resposta:**

As tags são `<figure>` e `<figcaption>`.

A `<figure>` agrupa a imagem e a `<figcaption>` é usada para colocar a legenda.

## Atividade 10

**Resposta:**

O atributo usado para informar o endereço de destino de um link é o `href`.

## Atividade 11

**Resposta:**

Um link interno leva para outra página ou arquivo do próprio projeto. Já o link externo leva para outro site.

Por exemplo, `contato.html` é um link interno e o site da MDN é um link externo.

## Atividade 12

**Resposta:**

A tag `<table>` representa a tabela.

A tag `<tr>` representa uma linha.

A tag `<th>` representa uma célula de cabeçalho.

A tag `<td>` representa uma célula comum da tabela.

## Atividade 13

**Resposta:**

Para criar um link de e-mail, usamos `mailto:` no `href`.

Exemplo:

```html
href="mailto:contato@exemplo.com"
```

## Atividade 14

**Resposta:**

A tag usada para representar o rodapé é a `<footer>`.

## Atividade 15

**Resposta:**

A tag usada para ligar o HTML com o CSS externo é a `<link>`.

O atributo que informa que o arquivo é uma folha de estilos é:

```html
rel="stylesheet"
```

## Atividade 16

**Resposta:**

A propriedade CSS usada para definir a família da fonte é `font-family`.

## Atividade 17

**Resposta:**

A propriedade `color` muda a cor do texto.

A propriedade `text-align` muda o alinhamento do texto.

## Atividade 18

**Resposta:**

É possível selecionar mais de um elemento na mesma regra separando os seletores por vírgula.

Exemplo:

```css
h2, h3 {
    color: darkgreen;
}
```

## Atividade 19

**Resposta:**

No CSS, uma classe é selecionada usando um ponto (`.`) antes do nome da classe.

No HTML, usamos o atributo `class` para colocar uma classe em um elemento.

## Atividade 20

**Resposta:**

Para selecionar um elemento pelo ID no CSS é usado o símbolo `#`.

Exemplo:

```css
#sobre {
    background-color: lightgray;
}
```

## Atividade 21

**Resposta:**

A propriedade que define a largura é `width`.

Para a altura se ajustar automaticamente pode ser usado o valor `auto`.

## Atividade 22

**Resposta:**

A propriedade usada para criar espaçamento interno é `padding`.

## Atividade 23

**Resposta:**

A propriedade usada para definir o espaçamento externo é `margin`.

A expressão `margin: 0 auto;` pode ser usada para centralizar um elemento de bloco horizontalmente.

## Atividade 24

**Resposta:**

A propriedade que permite fazer um elemento flutuar para um dos lados é `float`.

Para colocar o elemento do lado esquerdo usamos o valor `left`.

## Atividade 25

**Resposta:**

A propriedade usada para definir a largura da tabela é `width`.

A propriedade `border-collapse` serve para unir as bordas das células.

A propriedade `border` é usada para definir a borda de um elemento.

## Atividade 26

**Resposta:**

A propriedade usada para controlar a decoração do texto é `text-decoration`.

Para remover o sublinhado dos links usamos:

```css
text-decoration: none;
```

## Atividade 27

**Resposta:**

Para o rodapé ficar como foi pedido, pode ser usado:

```css
footer {
    background-color: lightgray;
    padding: 15px;
    text-align: center;
}
```
